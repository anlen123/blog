云南路线地图 · 丽江进出

🗺️ 云南 6 天路线地图

丽江三义机场进出 · 大理 → 丽江 → 香格里拉环线

高铁
汽车/打车
骑行/步行
📍 路线时间线 · Day 1 → Day 6（按行程顺序）
1
成都 → 丽江 → 丽江古城
抵达日 · 轻松适应
路段方式距离时间
成都天府/双流 → 丽江三义机场 ✈️ 飞机 ~700km 1.5h
三义机场 → 丽江古城（大研古城） 🚗 滴滴/出租 28km ~35min
下午+晚上：入住古城客栈，逛四方街→大水车→大研花巷→樱花餐厅夜景，看篝火打跳（20:00）
2
玉龙雪山 + 蓝月谷 + 白沙古镇
全天重头戏
路段方式距离时间
丽江古城 → 玉龙雪山游客中心 🚗 滴滴/包车 25km ~40min
游客中心 → 冰川公园索道下站 🚌 景区大巴 — ~20min
索道下站（3356m）→ 上站（4506m） 🚡 大索道 — ~15min
上站 → 4680m 石碑 🥾 步行栈道 ~1km 30-60min
雪山 → 蓝月谷 🚌 景区大巴 — ~15min
玉龙雪山 → 白沙古镇 🚗 滴滴 18km ~25min
白沙古镇 → 丽江古城 🚗 滴滴/公交 12km ~20min
3
丽江 → 大理古城 + 喜洲古镇
南下白族风情
路段方式距离时间
丽江古城 → 丽江站 🚗 滴滴 10km ~20min
丽江站 → 大理站 🚄 高铁 ~180km ~2h
大理站 → 大理古城 🚗 滴滴/公交 17km ~30min
大理古城 → 喜洲古镇 🚗 滴滴/中巴 20km ~30min
4
洱海全天 · 海西生态廊道骑行
精华骑行段
路段方式距离时间
大理古城 → 龙龛码头（骑行起点） 🚗 滴滴 5km ~10min
龙龛码头 → 磻溪S弯 🚴 景区电动车 ~15km ~1.5h（含拍照）
磻溪S弯 → 廊桥 🚴 景区电动车 ~8km ~45min
廊桥 → 海舌公园 → 喜洲 🚴 景区电动车 ~10km ~1h
喜洲 → 大理古城 🚗 滴滴 20km ~30min
💡 海西廊道禁机动车+禁外部电动车，用景区共享电动车 ¥30-80/天。全程 46km，量力而行，可只骑龙龛→磻溪精华段
5
大理 → 香格里拉 · 独克宗古城
北上藏地高原
路段方式距离时间
大理古城 → 大理站 🚗 滴滴 17km ~30min
大理站 → 丽江站（换乘） 🚄 高铁 ~180km ~2h
丽江站 → 香格里拉站 🚄 高铁 ~170km ~1h
香格里拉站 → 独克宗古城 🚗 滴滴 8km ~15min
古城 → 龟山公园（步行上山） 🥾 步行 — ~10min
下午+晚上：逛独克宗古城 → 爬龟山公园转世界最大转经筒（21m/60吨）→ 山顶俯瞰古城全景 → 月光广场锅庄舞 → 牦牛肉火锅
6
普达措国家公园 → 回丽江 ✈️ 成都
收官之日
路段方式距离时间
独克宗古城 → 普达措国家公园 🚗 滴滴/包车 25km ~30min
属都湖木栈道徒步 🥾 步行 ~3km 1-1.5h
普达措 → 独克宗古城（取行李） 🚗 滴滴 25km ~30min
独克宗古城 → 香格里拉站 🚗 滴滴 8km ~15min
香格里拉站 → 丽江站 🚄 高铁 ~170km ~1h
丽江站 → 三义机场 🚗 滴滴 28km ~35min
三义机场 → 成都 ✈️ 飞机 ~700km 1.5h
💡 选 19:00 以后的航班。香格里拉→丽江末班高铁约 17:00，倒推普达措最晚 14:00 离开。
